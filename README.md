## Using the notebooks

### In Google Colab

1. Select **Open in Colab** for the lab week you are covering.
2. Save a copy in your Google Drive so you can keep your edits.
3. Run cells in order, then use the practice sections to change or write code.

Follow each notebook's data-loading instructions. For Week 3's Pons exercise in Colab, upload `wk03_rcts_and_ate/data/pons_2018_teaching.csv` into a runtime folder named `data`. Data sources and preparation notes are in each week's `data/README.md`.

Coding-session practice is separate from lab submissions on Canvas.

### On your computer

Clone or download the full repository so the datasets are available, then install the Python packages:

```bash
python -m pip install -r requirements.txt
```

Open the matching notebook in Jupyter or your IDE and run cells in order.
