# Week 4 datasets

`kling_stratmann_subset.csv` is this week's copy of the course robocall extract:
539,567 voter records and eight columns. It is identical to the copies in
Weeks 3, 9, and 10. The Week 4 notebook uses this folder for both local loading
and its online CSV fallback.

Source: Kling, Daniel T., and Thomas Stratmann (2023),
[Large-Scale Evidence for the Effectiveness of Partisan GOTV Robo Calls](https://doi.org/10.1017/XPS.2022.16).

`nyvoterfile_2021.csv` is the existing voter-file dataset retained in this folder.
