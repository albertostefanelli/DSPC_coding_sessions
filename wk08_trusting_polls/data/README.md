# W8 data sources

- `phone_poll.csv` and `online_poll.csv`: copied unchanged from Joshua Kalla, `data_science_campaigns_26`, commit `c660719416923961732f1414fa960bf92de8baf1`, `wk08_trusting_polls/data/`. These are instructional case inputs, not verified real pollster releases. The case supplies age targets 0.180, 0.250, 0.321, 0.249 for 18–29, 30–44, 45–64, 65+.
- `ces_2018_teaching_sample.csv`: all 1,000 rows of Shiro Kuriwaki's `cc18_samp` teaching object, reduced to `case_id`, `birthyr`, `pid3`, `commonweight`. No new sampling or synthetic rows. [Versioned source](https://github.com/kuriwaki/ccesMRPprep/blob/e4482502dbebc00ca4060c29c7e532272d4b03c6/data/cc18_samp.rda), retrieved 2026-09-15. R `load` and `write.csv` preserve original numeric values; unused columns dropped. `pid3`: 1 Democrat, 2 Republican, 3 Independent, 4 Other, 5 Not sure, 8 skipped, 9 not asked. `commonweight` is the original common-content weight. This small teaching subsample is for weighting arithmetic; it is not a replacement for a full-survey national estimate.
- Original CES citation: Schaffner, Brian; Ansolabehere, Stephen; Luks, Sam (2019), *CCES Common Content, 2018*, Harvard Dataverse, [doi:10.7910/DVN/ZSBZ7K](https://doi.org/10.7910/DVN/ZSBZ7K). [Teaching sample documentation](https://github.com/kuriwaki/ccesMRPprep/blob/e4482502dbebc00ca4060c29c7e532272d4b03c6/R/datadoc_cces-common-samp.R). Weighting party identification uses a pre-election response; no vote-validation missing values are recoded as nonvoting.
- `dime_candidates_2020_2024_clean.csv`: existing course data retained unchanged. Adam Bonica (2024), DIME public version 4.0, [Stanford](https://data.stanford.edu/dime).
